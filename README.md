## Purpose of the Site
This project is a responsive static website built collaboratively as part of a web development assignment.

The purpose of the site is to:
- Showcase our team and individual work
- Demonstrate proper GitHub collaboration practices
- Practice version control using branches and pull requests
- Intentionally create and resolve merge conflicts
- Implement responsive design using Bootstrap
- Integrate basic JavaScript interactivity

This repository will continue to be developed and expanded throughout the semester.

## Features Implemented

- Merge conflict creation and resolution

## Development Workflow
- Feature branches used for new functionality
- Pull requests required before merging into `main`
- Clear commit messages documenting changes
- Collaboration between team members through code reviews
